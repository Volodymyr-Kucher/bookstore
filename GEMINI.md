## 📚 Структура проєкту Bookstore
- **`bookstore/`** — власний проєкт користувача:
  - Spring Boot 3.4.x, Java 21, Maven.
  - Сутність: `Book` (книгарня).
  - Реалізовано повний CRUD (Завдання 1.1 та 1.2):
    - `GET /api/books` (перелік усіх книг)
    - `GET /api/books?genre={genre}` (фільтр за жанром)
    - `GET /api/books/{id}` (деталі)
    - `POST /api/books` (створення з валідацією, 201)
    - `PUT /api/books/{id}` (оновлення, 200 / 404)
    - `DELETE /api/books/{id}` (видалення, 204 / 404)
    - Початкове наповнення: `BookSeeder` (5 книг).
- **`l1b/`** — навчальні матеріали курсу (еталонний проєкт `amazonua`, лекції та завдання). Знаходиться у `.gitignore`.
