# Книгарня — Spring Boot backend

Навчальний проєкт інтернет-магазину книг на Spring Boot 3.4.x / Java 21.

## Архітектура

Багатошарова архітектура з інтерфейсами на межах шарів:

```
domain/        — доменна модель (Book)
repository/    — інтерфейс + in-memory реалізація
service/       — бізнес-логіка + маппер
web/           — REST-контролер + DTO
config/        — сидер початкових даних
exception/     — власні винятки
```

## Ендпоінти

| Метод  | URL                            | Опис                      | Код |
|--------|-------------------------------|---------------------------|-----|
| GET    | `/api/books`                  | Перелік усіх книг         | 200 |
| GET    | `/api/books?genre=Поезія`     | Фільтр за жанром          | 200 |
| GET    | `/api/books/{id}`             | Одна книга (деталі)       | 200 |
| POST   | `/api/books`                  | Створити нову книгу       | 201 |
| PUT    | `/api/books/{id}`             | Оновити книгу             | 200 |
| DELETE | `/api/books/{id}`             | Видалити книгу            | 204 |

Неіснуючий `id` → `404 Not Found`.

## Запуск

```bash
./mvnw spring-boot:run
```

Або запустіть клас `BookstoreApplication` у IntelliJ IDEA.
